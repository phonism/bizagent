Knowledge

            
Layered, read-only knowledge: common (all businesses) → line (this product line) → business (this one). Files are the source of truth — agents and curators write them, the UI only displays.

            

          

        

      


      
      

        

          

            
Modules & Skills

            
Modules: the code components this business is built from (knowledge only — the agent never executes them). Skills: capabilities agents can load on demand. Read-only here; files are the source of truth.

            

          

        

      


      
      

        

          

            
Tasks (requirements)

            
A requirement is a multi-session task container: a directory whose requirement.md is the living state doc every session on it shares. Sessions link via a .req marker; their context is injected at launch.
